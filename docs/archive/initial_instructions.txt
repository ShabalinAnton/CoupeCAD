В данном файле репозитория собраны инструкции для создания приложения на языке C++ для создания кроссплатформенного приложения с использованием библиотеки Qt (QML).

Название приложения: CoupeCAD
Описание: CoupeCAD - это приложение для создания шкафов, шкафов-купе, гардеробов, кухонных гарнитуров и других видов шкафов. 
Приложение позволяет пользователю создавать 3D-модели шкафов, настраивать их размеры, материалы и фурнитуру, а также генерировать чертежи и спецификации для производства.
Приложение позволяет импортировать модели из таких форматов, как .obj, .dxf, .dwg. 
Приложение также поддерживает экспорт моделей в форматы .obj, .stl, .dxf, .dwg для использования в других CAD-программах или для 3D-печати.
Приложение будет иметь интуитивно понятный интерфейс, который позволит пользователям легко создавать и настраивать свои проекты. 
Приложение будет поддерживать различные языки, включая русский, английский и другие, чтобы обеспечить удобство использования для пользователей по всему миру.
Приложение должно быть расчитано на пользователей с различным уровнем опыта, от новичков до профессионалов, и предоставлять широкий спектр инструментов и функций для создания шкафов любой сложности.
Приложение будет поддерживать различные платформы, включая Windows, macOS и Linux, webassembly, чтобы обеспечить доступность для широкого круга пользователей. 
Приложение должно содержать встроенные шаблоны и библиотеки материалов, а также возможность создавать и сохранять свои собственные шаблоны и материалы для повторного использования в будущих проектах.
Приложение должно обладать возможностью параметрического моделирования, что позволит пользователям легко изменять размеры и пропорции своих проектов без необходимости вручную редактировать каждую деталь.
Приложение должно уметь выдавать подробные отчеты о материалах и стоимости проекта, чтобы помочь пользователям планировать свои бюджеты и закупки.
Приложение должно уметь рендерить высококачественные изображения своих проектов, чтобы пользователи могли визуализировать свои идеи и делиться ими с другими.

Технологии и инструменты:
- Язык программирования: C++
- Фреймворк: Qt (QML для интерфейса и C++ для логики приложения)
- Система контроля версий: Git
- Сборка: CMake
- Пакетный менеджер: conan
- Система непрерывной интеграции: GitHub Actions
- Система управления проектами: GitHub Projects
- Система отслеживания ошибок: GitHub Issues
- CAD ядро: OpenCASCADE
- Для локальной БД можно использовать SQLite.
